# 美术资源放置规则

地图编辑器按当前图层递归读取地面或装饰调色板。将可绘制的 **Tile 或 Rule Tile `.asset`** 放到下表对应目录，切换图层即可看到。瓦片专用的 PNG 与它生成的 Tile 放在同一子目录，PNG 需先导入为 Sprite。

| 地图图层 | 相对 `Assets/Game/Art` 的目录 | 放置内容 |
| --- | --- | --- |
| Background（背景） | `Environment/<主题>/Background/` | 一张完整的房间底图。地图编辑器直接显示该目录及子目录中的图片缩略图，点击即可应用，可等比裁切填满或完整显示留边 |
| Ground（地面） | `Tiles/Ground/` | 地面、墙边和平台本体。需要实体碰撞时，在地面层绘制并勾选「同时绘制实体碰撞」 |
| Decoration（装饰） | `Tiles/Decoration/` | 逐格摆放的装饰、平台顶边和其他视觉细节 |

各调色板可以在目录内按 `Indoor`、`Outdoor` 划分主题，主题下再按用途建子目录。示例中的平台本体位于 `Tiles/Ground/Indoor/Platforms/`，平台顶边位于 `Tiles/Decoration/Indoor/Platforms/`。

## 场景摆件和其他素材

- `Environment/Indoor/`、`Environment/Outdoor/` 存放环境素材。房间底图放在 `Background`。门、吊灯等房间摆件放在 `Decorations`，教堂、塔楼等中景放在 `Midground`。这些图片导入为单张 Sprite 后，可通过地图编辑器的「绘制 → 环境摆件」放入房间。天空和远景分别放在 `Sky` 和 `Distant`，可在场景中独立摆放。
- `Environment/<主题>/References/` 存放示例图和构图参考。
- `Characters/`、`Enemies/`、`UI/`、`VFX/` 分别存放角色、敌人、界面和特效资源。

地图网格每格为 0.5 世界单位。新瓦片做好后，在地图编辑器中检查单格占用和连续铺贴的接缝。例如，16 × 16 的单格 Sprite 使用 32 PPU 时宽高各占一格。迁移已有资源时，用 Unity Project 窗口移动，或在文件系统中连同原 `.meta` 文件一起移动，以保留场景引用。
